# Objectives

## Learning goals

- [ ] Stand up a working Wazuh manager + agent pipeline from scratch
- [ ] Deploy and tune a non-default Sysmon config (reference a known baseline, e.g. SwiftOnSecurity or Olaf Hartong's, and document deviations)
- [ ] Establish a documented "normal" baseline before introducing any attack simulation
- [ ] Simulate at least 3 distinct attack techniques (e.g. brute force, suspicious PowerShell, persistence via account creation) and detect each one
- [ ] Write a full incident report for at least one alert, including a timeline reconstructed from raw logs
- [ ] Run at least one proactive threat hunt not triggered by an existing alert
- [ ] Identify and document at least one real detection gap, with a proposed fix
- [ ] Track basic SOC metrics (MTTD, MTTR, alert-to-incident ratio) across the project

## Definition of done (for this project)

This project is "portfolio-ready" once:
1. Environment setup docs are reproducible by someone else following them
2. At least 3 alert investigations are fully written up
3. At least 1 incident has a complete timeline and report
4. The metrics sheet reflects real data, not placeholders
