# Write-ups

Hack The Box write-ups, split by type:

- [`htb-machines/`](htb-machines/) — full machine walkthroughs (enumeration → foothold → privesc)
- [`htb-challenges/`](htb-challenges/) — standalone challenges (web, crypto, forensics, pwn, etc.)

## Rules for posting write-ups

- **Retired boxes/challenges only.** Do not publish write-ups for active machines or challenges — this is an HTB ToS requirement.
- **No flags.** Describe the technique used to get the flag, never the flag value itself.
- Redact any personal info, real IPs that aren't the lab's, or license keys accidentally captured in screenshots.
