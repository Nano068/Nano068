## Adding a certification

1. Copy [`TEMPLATE.md`](TEMPLATE.md) to a new file named after the cert (e.g. `oscp.md`).
2. Fill it in with prep resources, exam notes (nothing that violates the cert's NDA — summarize your process, not exam content), and what you'd tell someone starting the same path.
3. Add a row to the table above.
